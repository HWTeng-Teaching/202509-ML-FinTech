# README

## The Fraud Intelligence Engine: A Hybrid Framework Merging Feature Crafting and Comparative Learning  
### Authors: Huei-Wen Teng, Cheng-Min Tsai, Nguyen-Thu Thu

---

### 介紹
本專案展示一個結合特徵工程與比較學習的詐騙偵測框架，旨在提升模型準確性與可解釋性。透過多模型評估、特徵比較與視覺化分析，本研究提出一套能有效應對詐騙識別挑戰的完整方法流程。

---

### 程式檔案

- **EDA_senba-beth.ipynb**：前期 EDA 數據探索與分析。

- ~~**test_proposal.ipynb**~~：數據測試（已棄用）。

- **test_benchmark.ipynb**：benchmark 測試，建立多模型性能比較基準。

- **test_research_design.ipynb**：方法研究設計與實作，呈現主要模型與研究流程。

- **senba-result.csv**：40 種模型評估最終輸出結果。

- **models-compare-table.xlsx**：40 種模型評估最終結果的彙整表格。

- **summary_results.ipynb**：圖表分析、數據視覺化與研究結論摘要。
